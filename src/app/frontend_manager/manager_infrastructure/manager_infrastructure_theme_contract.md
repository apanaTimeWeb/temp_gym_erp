# Manager Infrastructure — Theme Contract

Shared primitives remain business-agnostic. Use semantic theme tokens only; do not introduce raw palette shades, arbitrary hex/RGB colors, or feature-specific business colors. Preserve contrast, visible keyboard focus, reduced motion, and accessible status announcements.
