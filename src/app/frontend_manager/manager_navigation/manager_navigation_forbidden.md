# Manager Navigation — Forbidden Patterns

- No feature business logic, API calls, query keys, state, schemas, or feature data.
- No hard-coded leaf URLs when a canonical URL config exists.
- No duplicate competing registries.
- No inaccessible clickable divs, unlabeled icon buttons, or submenu controls without aria-expanded/aria-controls.
- No removal of direct leaf routes or compatibility redirects without approved migration.
- No raw palette colors, inline styles, or localization-key deletion.
