# Admin Reports Cross-Domain Overview — Theme Contract

## Consumed global tokens
- Surfaces: `bg-page`, `bg-card`, `bg-header`, `bg-surface-hover`, `bg-surface-highlight`
- Text: `text-primary`, `text-secondary`
- Borders and focus: `border-border`, `ring-primary`
- Layout: responsive grid and minimum 44px link-card action area

## Responsive and accessibility contract
- Cards flow at mobile/tablet/desktop widths.
- All navigation is a semantic anchor with visible keyboard focus.
- Icons are decorative and hidden from assistive technology.
- Motion is limited to `transition-colors` and remains nonessential.
