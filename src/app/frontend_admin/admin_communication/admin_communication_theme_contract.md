# Admin Communication — Theme Contract

Global semantic tokens consumed by the domain navigation shell: `bg-page`, `text-primary`, `bg-header`, `bg-card`, `border-border`, `bg-surface-highlight`, `bg-surface-hover`, `text-secondary`, `border-focus`, `ring-primary`, `ring-offset-page`.

Use Inter and existing global layout tokens. No feature-specific tokens, inline CSS, raw color literals, or business-aware global primitives are introduced by the parent shell.
